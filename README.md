# Email-Notifier-Project
<br>
•	EmailNotifier monitors a Gmail inbox for new messages from specified senders.
<br>
•	Connects to the email account and checks for messages received since the current date.
<br>
•	The system sends notifications with details about the sender and subject of each new email.
<br>
•	It operates continuously at regular intervals, Keeping a log record of each new email received.
